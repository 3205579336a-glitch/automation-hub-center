# Purchasing Automation Hub — 0.3.0 操作指南

## 安装或升级

1. 完成或安全停止当前任务，退出旧版 Hub。
2. 将获准分发的 Windows ZIP **完整解压到新的本机可写文件夹**。保留 EXE、resources、locales 和 DLL，不要从压缩包内或网络盘直接启动。
3. 双击 **SAP Automation Toolbox.exe**，在侧栏底部确认版本为 **0.3.0**。原有个人设置和历史仍在本机。

用户不需要安装 Python、Node.js 或 pip。按任务需要，仍须具备公司 SAP GUI 及 Scripting、Excel、ME12 使用的 Chrome/Edge、公司网络/VPN 和相应权限。证书及 SAP 登录仍由本人处理。如被系统或终端安全软件拦截，请向 Key User 或 IT 确认，不要绕过安全策略。

## 执行任务

1. 打开**操作中心**，选择任务；点击**说明**查看简要步骤。
2. 需要 Excel 的任务先下载新版模板。保留表头，填好输入列，保存后上传。Excel 可保持打开，但运行时不要排序、移动或修改输入行。
3. 核对预览、业务选项和 SAP 环境，按提示开始或确认。
4. 通过右上角状态和任务页查看进度。结束后检查成功、跳过和失败明细；在**执行历史**可查看运行详情和结果位置。

同一时间只运行一个 SAP 任务。其他页面仍可打开、上传和预览，但「开始」按钮会禁用。点击**查看正在运行的任务**可返回当前任务。任务结束后，其他页面会自动解锁，并保留已经准备的内容。任务结果弹窗会等你返回对应页面再显示；SAP 需要人工处理时，全局「需要处理」仍会正常提示。

| 功能 | 输入与结果 |
| --- | --- |
| 批量创建 Buyer Receipt / RFQ | 填写 RFQ 模板。Hub 按工厂、项目和供应商分组，每份 RFQ 最多 50 个物料。核对正式系统提示和 RFQ 编号；如原表回写失败，使用保留的结果副本，不要为回写重复运行 SAP。 |
| 批量维护采购信息记录（ME12） | 填写信息记录号，每行至少填写 SLT、PDT 或 Conf. Ctrl. 一项。空白的修改项不变。工厂和采购组织默认 C100，采购类型默认标准＋寄售，分别查看 Excel 结果。如浏览器要求选择证书或登录，请本人完成。 |
| APQP 日期管理 | 「查找 APQP 并编辑日期」维护四个计划日期；「批量查询计划关闭日期」用 Excel 查询，不修改 SAP。 |
| Source List（ME01） | 填写物料号、Parma 和必填的是否双供 Yes/No。目标 Parma 已存在则跳过、不修改。新增时勾选 Fix、MRP 填 1；Yes 保留其他 Fix/MRP，No 清空其他 Fix/MRP，不删除供应商行或修改其日期。 |
| Sub-commodity（MM02） | 填写物料号和准确的六位代码，保留前导零。确认有 MM02 修改权限，在正式 949 保留一个停在 SAP 首页的空闲窗口。Hub 核对目标分类，单独生成结果 Excel，不修改输入表。 |

### APQP 计划日期

- 先核对项目和 **User ID**。符合格式的 Windows 登录名会自动填入；若 APQP 负责人不同，请手动修改。它只是查询条件，不是 SAP 登录账号。
- 日期页固定使用正式 SAP 949、工厂 C100。仅修改四个计划日期：RTS Confirmation、RTS Action & Closure、Total PPAP 和 APQP Closure。灰色字段不可改，实际日期、SD 确认和备注不变。
- 点击**保存日期**会写入正式 SAP。成功记录会重新打开并核实日期。若结果不确定，Hub 会安全停止；先核查 SAP，不要盲目重跑。
- **使用上次结果**显示历史查询，不代表 SAP 当前值；用**重新查询 SAP**获取最新数据。较旧的实际日期布局缓存不能复用，请从 SAP 重新查一次。「清空本页」清除结果和编辑，保留项目及负责人筛选条件。

## 仪表板、日志与安全恢复

- 从侧栏底部展开或折叠。语言、主题、字体、提示音在**设置**中调整；诊断位于**支持与日志**。
- **预计节省时间**显示「今日」和「全部时间」。只统计本机仍保留的记录，已清理历史不再计入。APQP 日期每个已保存并核实的字段按人工 1 分钟估算，再扣除整批耗时；这是估算，不是实际个人绩效。
- **安全停止**不撤销已保存的 SAP 变更。保存结果不确定时，先检查 SAP 和结果。RFQ 中断后，Safe Recovery 只引导人工核查，不自动恢复或重跑。
- 本机历史和符合条件的已完成任务文件在 60 天后清理，重要结果请提前另存。原始 Excel 和未核查 RFQ 证据受保护。分享日志前请检查是否包含业务信息。

向 Key User 报告问题时，提供版本号、功能、Run ID、可见报错和最后一步。不要通过未经批准的渠道发送密码、证书或正式业务表格。
